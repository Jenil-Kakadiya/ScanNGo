if setting up first time u have to install node_modules in both the client and server directory for that follow the step 3

->To run the Frontend 
  1. open new terminal
  2. run command: cd client
  3. Run the command if setting up first time : npm i
  4. run command: npm run dev

->To run the Backend 
  1. open new terminal
  2. run command: cd server
  3. Run the command if setting up first time : npm i
  4. run command: npm run dev
